# Plano de Entrega por Ator - SILIC 2.0

Este documento organiza o envio do protótipo de baixa fidelidade e da documentação para três públicos:

1. UX (protótipo de alta fidelidade no Figma)
2. Analista de Requisitos (formalização funcional)
3. Desenvolvedores (implementação do módulo)

## Fluxo oficial de encaminhamento

1. Time atual envia pacote para UX.
2. UX produz protótipo de alta fidelidade no Figma e devolve com observações.
3. Time atual envia pacote consolidado (documentação + Figma) para Analista de Requisitos.
4. Analista de Requisitos valida e abre a demanda para Desenvolvedores da fábrica.
